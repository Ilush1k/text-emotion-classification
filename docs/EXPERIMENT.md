# Описание эксперимента

Корпус содержит английские тексты с шестью эмоциональными метками. Для классических моделей используются подготовленные лемматизированные тексты; DistilBERT получает представление до лемматизации. Словари TF-IDF, Word2Vec и параметры масштабирования строятся на train.

Validation используется для выбора параметров и эпох. После выбора выполняется сравнение на test. Дополнительно показывается постоянный ответ самым частым классом. Итоговые таблицы и графики доступны в ноутбуке.

В данных используется автоматическая разметка, поэтому качество оценивает согласие с этими метками. Один seed, ограниченный подбор, усреднение Word2Vec, ограничение длины DistilBERT и возможные близкие перефразировки между частями корпуса ограничивают перенос результатов. Очень высокая метрика DistilBERT требует проверки на независимом наборе до практического применения.

Точная авторская выгрузка CSV не распространяется. Скрипт загрузки использует текущую версию общедоступного источника; состав может отличаться. Замеры README относятся к сохранённой авторской версии.

Исходный обновлённый ноутбук в рабочей папке оставлен без исправлений; минимальная правка заключения сделана только в публичной копии. Word-описание именно этой версии среди просмотренных документов не найдено, поэтому описание подготовлено по коду и сохранённым выводам.
