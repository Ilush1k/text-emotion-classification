# Данные Emotion

Источник, указанный автором: [DAIR.AI Emotion](https://huggingface.co/datasets/dair-ai/emotion); описание набора — [CARER](https://aclanthology.org/D18-1404/).

Ноутбук ожидает CSV `emotion.csv` в корне с полями `text` (английский текст) и `emotion` (anger, fear, joy, love, sadness, surprise). Входной CSV и веса моделей не публикуются. Метрики сохранённого запуска относятся к авторской выгрузке, поэтому другая версия корпуса может дать другие результаты.

Используйте свой исходный `emotion.csv` или скрипт `scripts/download_data.py`, который получает общедоступный корпус через библиотеку datasets и приводит поля к ожидаемым. Перед использованием данных прочитайте карточку набора и условия источника.

В карточке источника указан учебный и исследовательский характер использования. Скрипт выбирает конфигурацию `unsplit` и получает текстовые метки из описания поля `label`, сохраняя правильное соответствие классов.
